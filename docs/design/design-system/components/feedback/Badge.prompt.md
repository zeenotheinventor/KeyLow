Badge labels a food's source or a short status; the text always carries the meaning.

```jsx
<Badge kind="source" source="off" />
<Badge tone="warning" dot>Needs review</Badge>
<Badge tone="success">Complete</Badge>
<Badge tone="neutral">Estimate</Badge>
```

Pill, 20 px tall, caption type. Status tones use the *-muted background with the full colour as text.

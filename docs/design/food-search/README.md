## Decisions

Where the sources disagree, the order is: Zee's rulings, then the Ki-Lo design system (`../design-system/`), then MacroFactor for layout and behaviour, then the briefs. Zee approved these boards on 2026-10-13. Anything that would visibly change a board goes back to Zee first.

- **A full-screen sheet, not a stack screen.** Food search opens from the "Search for a food" bar above the tab bar on Dashboard and Diary, or from the centre "+". It has a close control, a docked search field at the bottom and no tab bar. Food detail, the food form and the barcode scanner open inside the same sheet.
- **Grouped by source, no badge on rows.** Results come in the fixed order Your foods, Common foods (UK CoFID), Branded foods (Open Food Facts, saved in Ki-Lo) and From Open Food Facts (live). Each heading carries the plain source name as a caption. Rows show the name with the matching words in bold, the brand, a macro line (P, C, F, in that order, as the design system's MacroBars) and the energy.
- **Macro order is P, C, F.** The design system outranks MacroFactor's P, F, C order.
- **"See N more" sits right-aligned beside the group heading**, as in MacroFactor. The design system is silent on it.
- **Sheet surfaces.** The body sits on `--background` and the header and docked field on `--surface-sheet`, because rows and cards sit on `--surface`, which is darker than the sheet and would invert the stack.
- **Your foods (Zee, Q13 yes).** "Your foods" under More opens this sheet titled "Your foods", listing the user's own foods before any query. The boards are `your-foods` and `your-foods-empty` (empty copy: "No foods yet", "Foods you create or copy appear here.", action "Create a food"). Typing filters the user's own list on the client and keeps the title. It does not widen to shared or Open Food Facts results.
- **Open Food Facts is searched live only when the local search finds fewer than 5 foods.** Its failure is a quiet neutral banner, never red, because the user's own results still work. The rate-limited variant reads "Open Food Facts is busy. Try again in 30 seconds." and has no retry button, since the search runs again when the query changes.
- **`history-proposal` is not M2 scope.** MacroFactor opens search on Favourites and Recent. That needs food logging, so it is drawn as a proposal for M3 only and nothing is built from it.
- **Out of scope for M2:** logging, portions and quantities, the multi-add "+" on rows, a plate, quick add, filters and sorting.

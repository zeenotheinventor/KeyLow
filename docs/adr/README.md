# Architecture decision records

An ADR here is a short, dated record of an architecture decision that was already made elsewhere (usually the Build Plan & Engineering Context document) and is now frozen so later milestones reference it instead of re-deriving it each time.

To add one, pick the next number, copy the heading structure of an existing ADR (Title, Status, Context, Decision, Consequences), and fill it in.

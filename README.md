# KeyLow

A MacroFactor-style nutrition app: recipes, calorie and macro diary, weight trend, and an adaptive engine that estimates energy expenditure and adjusts targets weekly. Expo (iOS and Android) and a Next.js web dashboard on a shared TypeScript core, backed by Supabase.

Planning and engineering context live in Linear: project **KeyLow v1** and its document **Build Plan & Engineering Context**. Read that document before picking up a ticket.
